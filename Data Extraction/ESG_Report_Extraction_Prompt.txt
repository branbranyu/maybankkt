
ESG Report Extraction Task: Can you help me scan and extract the ESG metric values from the uploaded company ESG/Sustainability report, and complete a structured Excel file using the format and instructions below.

Important Notes:
Limit the task to 30 minutes.
Only give me the final populated table.

Output Format: Completed Excel file named: {Company Name}_Extracted_ESG_Metrics.xlsx

Each row corresponds to one of the 44 predefined ESG metrics and includes the following columns:

| Column Name         | Description                                               |
|---------------------|-----------------------------------------------------------|
| Metric Name         | Name from the predefined list            		  |
| Extracted Value     | Most recent value found			                  |
| Extracted Text      | Supporting sentence, bullet or table row                  |
| Remarks             | One tag from the list below                               |

Key Instructions
1. Start by scanning summary/KPI tables, usually near the end of the report.
2. Then perform a complete and exhaustive pass through the full report in this order:
   - Executive summary
   - ESG strategy or performance sections
   - Framework disclosures (e.g., GRI, SASB, TCFD, CDP)
   - Appendices, footnotes, glossary
3. Extract metrics systematically and individually. Keep track of what's found or missing.
4. If multiple values are present, prefer:
   - Most recent reporting year
   - Summary/KPI tables over scattered narrative
   - Values with explicit units and clear attribution
5. Once all 44 metrics are reviewed and populated, output the final Excel file.

Remarks Tagging Guide
Use one of the following tags for each metric:

| Tag          | Description                                                                 |
|--------------|-----------------------------------------------------------------------------|
| [Direct]     | Value is explicitly stated (e.g., "Scope 1 emissions: 30,000 tons CO₂e")    |
| [Inferred]   | Deduced from clear context (e.g., calculated from subtotals)                |
| [Estimated]  | Approximate from vague data (e.g., estimated from a bar chart)              |
| [Assumed]    | Based on logical assumption due to missing details                          |
| [Unavailable]| Metric could not be found or inferred in time                               |
